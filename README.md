# Automation & AI Documentation Library

A public collection of practical documentation covering IT automation, artificial intelligence, infrastructure, security, Microsoft 365, PowerShell and related technologies.

The aim of this repository is simple: share useful, reusable technical material that helps IT professionals investigate problems, automate repetitive work and use AI more responsibly.

## What You Will Find Here

- AI and prompt engineering guides
- PowerShell scripts and automation documentation
- Microsoft 365 and Power Platform build guides
- Architecture notes, project plans and technical white papers

## Using These Resources

1. Open the relevant folder or document.
2. Check the version and any prerequisites.
3. Review the full guidance before using commands or procedures.
4. Test changes in a lab or limited scope before production use.
5. Keep change control, security policy and human approval authoritative.

## Responsible AI Use

Some documents in this repository were developed with assistance from generative AI. All published material has been selected, reviewed, edited and structured by a human author.

AI-generated output can be incomplete, outdated or confidently incorrect. It must not be treated as operational approval, a security verdict or a substitute for professional judgement.

Never submit passwords, access tokens, private keys, personal information, customer data or confidential logs to an AI service unless your organisation has explicitly approved it.

## Technical Disclaimer

These resources are provided for education, reference and community use. Environments differ, and no document can account for every dependency, configuration or risk.

Before applying technical guidance:

- Confirm compatibility with your environment and software versions.
- Understand the read/write effect and required privileges.
- Define success, failure, abort and rollback conditions.
- Follow your organisation's security and change-management processes.
- Maintain backups and recovery options where appropriate.
